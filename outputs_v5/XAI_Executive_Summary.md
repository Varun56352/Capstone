# XAI Cybersecurity Threat Detection - Executive Summary

This report automatically summarizes the performance and Explainable AI (XAI) insights generated by the pipeline.

## 1. The Dataset Shift Problem
By comparing models evaluated on the *same* dataset versus a *different* dataset, we observe the core challenge of network intrusion detection:

- When a model trained on TON_IoT is evaluated on the **same** dataset (TON_IoT), the best model (RandomForest) achieves an F1-score of **0.99**.
- When transferring that training to a **different** dataset (UNSW-NB15), the baseline performance drops drastically. The best model (SVM) achieved an F1-score of **0.89**.

## 2. The Power of XAI Feature Selection
A key finding of this pipeline is that forcing models to rely ONLY on the top features chosen by SHAP or LIME often acts as a powerful regularizer, restoring performance during cross-dataset transfer.

- Out of the tested cross-dataset transfers, utilizing SHAP-selected features improved the model's generalization capabilities in **3** instances compared to using the entire raw feature set.
